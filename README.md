### 🚀 What I'm building

- 🤖 **[Shane.ai](https://github.com/subhrajeetshaw008-bit/Shane.ai)**: a personal AI assistant, built from scratch. It runs on a local LLM via Ollama, wakes on a wake word, talks back with offline TTS, and handles to-dos, reminders, habit tracking, and daily scheduling. I'm currently adding a Streamlit web UI, expense tracking, and a study assistant.
- ⛰️ **[SIH-Landslide-Early-Warning](https://github.com/subhrajeetshaw008-bit/SIH-Landslide-Early-Warning)**: a Python project for early landslide detection and warning.
